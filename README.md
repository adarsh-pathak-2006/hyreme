# HYREME Platform Workspace

This directory contains the implementation workspace for HYREME.

## Current status

- `recruiter-web/`: recruiter-first Next.js application
- `recruiter-api/`: reserved for the backend service
- `shared/`: reserved for shared types, API contracts, and validation schemas

## Build order

1. Recruiter web MVP
2. Recruiter authentication and verification API
3. Candidate feed and recruiter action APIs
4. Messaging and interview scheduling services
5. Candidate-facing application
